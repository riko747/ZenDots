# 🎮 ZenDots

ZenDots is a **relaxing anti-stress casual game**, where you tap on balls in the correct sequence.  
Think of it like **digital bubble wrap** — simple, satisfying, and calming.  

---

## ✨ Features
- ✅ Relaxing gameplay — tap dots in the right order  
- ✅ Satisfying animations & "pop" sounds  
- ✅ Ripple effects and smooth transitions  
- ✅ 20 handcrafted levels (with ScriptableObjects)  
- ✅ Zen Mode (endless flow of dots)  

---

## 🎮 How to Play
1. Tap the dots in the correct sequence (1 → 2 → 3...)  
2. Enjoy satisfying **pop animations and sounds**  
3. Complete levels and relax ✨  

---

## 🛠 Tech Details
- Built with **Unity (C#)**  
- **Zenject** for dependency injection  
- **DOTween** for animations
